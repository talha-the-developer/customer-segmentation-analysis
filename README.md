Cu#stomer Segmentation Analysis
An exploratory data analysis (EDA) project using Python to identify patterns in retail customer spending habits.

🚀 Overview
This project analyzes a synthetic dataset of 500 customers to understand the relationship between Age, Annual Income, and Spending Score.

🛠️ Tech Stack
Python: Core programming logic.

Pandas: Data manipulation and cleaning.

Matplotlib: Statistical data visualization.

📈 Key Findings
Spending Clusters: Identified specific age groups with the highest spending scores.

Income Trends: Analyzed how income levels correlate with preferred shopping categories like Electronics or Clothing.
